# Calculadora de Média 🎓

## 📝 Descrição

Um script simples desenvolvido em Python que recebe duas notas de um aluno, calcula a média aritmética e informa o status final. Se a média for maior ou igual a 7.0, o aluno é considerado **APROVADO**, caso contrário, será **REPROVADO**.

## 💻 Tecnologias Utilizadas

* **Python 3.x**: Linguagem de programação utilizada para a lógica do sistema.

## 🚀 Como instalar e executar

Para rodar este projeto na sua máquina, siga os passos abaixo:

1. **Pré-requisitos**: Certifique-se de ter o [Python](https://www.python.org/downloads/) instalado no seu computador.

2. Crie um arquivo chamado `notas.py` (ou qualquer outro nome de sua preferência) e cole o código do projeto nele.

3. Abra o terminal ou prompt de comando.

4. Navegue até a pasta onde o arquivo foi salvo.

5. Execute o script com o seguinte comando:

```
python notas.py
```

## 💡 Exemplo de Uso

Ao executar o script, o programa irá interagir com o usuário pedindo as notas. Veja um exemplo de execução:

```
===Sistema de Notas do Aluno ===
Digite a primeira nota: 8.5
Digite a segunda nota: 7.0
A média final é: 7.75
Status: APROVADO!
```

Outro exemplo (caso o aluno seja reprovado):

```
===Sistema de Notas do Aluno ===
Digite a primeira nota: 5.0
Digite a segunda nota: 6.0
A média final é: 5.50
Status: REPROVADO!
```
